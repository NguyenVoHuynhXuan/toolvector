### What is CodeRabbit?

CodeRabbit acts as an automated, highly intelligent reviewer for your software development lifecycle. By deeply integrating into your Git workflow, it provides contextual feedback directly on pull requests, ensuring high code quality and catching potential security vulnerabilities before they make it to production.

- **Automated AI Code Review**: Get immediate, contextual feedback on every pull request to accelerate merge times.
- **Security Scanning**: Continuously scan your entire codebase for vulnerabilities and receive automated fix suggestions.
- **Explainability Layer**: Understand complex code changes effortlessly with AI-generated explanations and summaries of PRs.
- **Open Source Friendly**: Completely free to use for public and open-source repositories.

### Core Technology: Repository-Wide Context vs Raw Diff Scanning

Traditional code review bots suffer from high false-positive rates because they operate strictly on raw text diffs without understanding application runtime context. When a pull request modifies a shared utility function, raw diff scanners evaluate the changed lines in isolation without verifying downstream callers.

CodeRabbit solves this fundamental limitation by combining broad Large Language Models with code-graph analysis, your team's own Knowledge Base, and sandboxed static analysis.

- **Code Graph Analysis**: Upon receiving a webhook trigger from your Git platform, CodeRabbit builds a code graph of the symbols, definitions and dependencies touched by the change across mainstream languages and since August 2026, Vue, Svelte, Astro, Razor, XAML and .NET project and solution files so it can reason about impact beyond the diff.
- **Knowledge Base Context**: Every review draws on your organization's Knowledge Base - Learnings captured from past review conversations, Code Guidelines (including CLAUDE.md, AGENTS.md and standards files kept in a central repository), linked Jira, Linear or Azure Boards issues, Multi-Repo Analysis of linked repositories, and any connected MCP servers.
- **Sandboxed Verification**: CodeRabbit passes AST structural hints to LLM prompts. It runs 40+ linters, SAST and security tools (ESLint, Ruff, Semgrep, OpenGrep, Gitleaks, ast-grep and more) in a secure sandbox alongside the AI review, reducing the risk that the AI hallucinates and offering one-click fixes for the issues those tools surface.

### In-Depth Feature Evaluation & Workflow Integration

#### 1. Repository-Wide Context & Multi-Repo Analysis
CodeRabbit reviews each change against the wider codebase. With Multi-Repo Analysis, teams link related repositories so that a change to a shared API or type in one repository is checked against the services that consume it, catching cross-repository breaking changes before they merge. Plans include from one (Essentials) to twenty (Enterprise) linked repositories, and reviewers can pin which branch or pull request of a linked repository to review against.

#### 2. PR Walkthroughs, Sequence Diagrams & Change Stack
For complex pull requests touching multiple microservices, CodeRabbit automatically parses execution flow and generates interactive Mermaid sequence diagrams in the PR Walkthrough comment, alongside a summary, estimated review effort, related PRs and suggested reviewers. Engineering leads can visualize system data flow within seconds without clicking through dozens of individual file diffs.

For deeper inspection, the Review Change Stack button opens CodeRabbit's own review interface, which reorganizes a pull request from a flat list of files into a layered, cohort-by-cohort walkthrough with per-range AI summaries, an Architecture Impact before-and-after diagram, and the complete human and bot review history in one place. Change Stack is available on GitHub, GitLab, Azure DevOps and Bitbucket.

#### 3. Interactive Line-by-Line Code Suggestions & Chat
Developers can reply directly to any CodeRabbit review comment on GitHub, GitLab, Azure DevOps, or Bitbucket by tagging @coderabbitai. CodeRabbit responds inline within seconds with updated, copy-paste ready code blocks or one-click committable patches.

#### 4. CodeRabbit Security: Vulnerabilities, Secrets & Dependencies
Every pull request review includes security analysis, drawing on integrated tools such as Gitleaks, Semgrep and OpenGrep alongside the AI review. Security findings carry a vulnerability class, the CWE weakness title, and a reachability tier that tells reviewers whether the risky code path is directly reachable, conditionally reachable, or unlikely to be reached, with an entry-point-to-sink path as evidence. On the Advanced and Enterprise plans, CodeRabbit Security (currently in beta) extends this beyond the pull request: it scans existing codebases on demand or on a schedule for code vulnerabilities, leaked secrets and vulnerable dependencies; verifies whether detected secrets are still active; links dependency findings to their CVE records; and maps a repository's attack surface (entry points, trust boundaries, access controls and sinks) into a living view that flags when merged changes make earlier verification stale. Full-codebase AI Deep Scan is usage-based and billed separately.

#### 5. Finishing Touches, Fix CI & Post-Merge Actions
Finishing Touches are post-review agentic actions triggered from a checkbox in the PR Walkthrough or a comment: Autofix, docstring generation, unit-test generation, code simplification, custom recipes, Resolve Merge Conflicts, and Fix CI. Comment @coderabbitai fix-ci and CodeRabbit investigates the failing checks in a sandbox and opens a stacked pull request (or commits directly to the branch) with the fix. Post-Merge Actions run after a pull request lands: define up to five natural-language instructions, append a changelog entry, file a Jira or Linear ticket, post a Slack summary and CodeRabbit executes them against the merged change, opening a follow-up pull request for anything that modifies code. Both are Team-plan features and run across GitHub, GitLab, Azure DevOps and Bitbucket Cloud.

#### 6. Review Wherever Code Is Written: IDE, CLI & Coding-Agent Skills
CodeRabbit is not only a pull-request bot. The VS Code extension reviews committed and uncommitted changes inside the editor and hands findings to your configured AI coding agent. The CodeRabbit CLI runs the same review from the terminal, in CI, in pre-commit hooks, or against a remote GitHub repository without a local clone (cr review --remote owner/repo) and ships natively on macOS, Linux and, since August 2026, Windows, with EU-region authentication for European teams. The coderabbit skills command installs verified CodeRabbit skills into Codex, Claude Code, Cursor, Gemini CLI and GitHub Copilot, so coding agents can request a review and fix findings as part of their own loop. The IDE extension and CLI are available on every plan, including Free.

#### 7. Triage & CodeRabbit Agent
Two newer products address the volume of agent-generated code. Triage (Team plan, beta; GitHub and GitLab Cloud) is a self-updating, cross-repository queue that tells reviewers which pull request to look at next, how deeply to review it, and which pull requests can be closed, with one-click access to Change Stack, a CodeRabbit review, and CI or merge-conflict repair. CodeRabbit Agent for Slack and, for eligible open-source communities, Discord investigates issues, generates codebase-aware implementation plans, and opens pull requests from the conversation where engineers already coordinate; it can run automations from triggers such as PagerDuty incidents and connects to 40+ external services through a single Connections page shared with PR review. Agent usage is billed at $0.40 per agent-minute.

### Enterprise Compliance, Privacy & Data Security

Security and data privacy are foundational requirements when introducing AI-driven automated review bots into proprietary enterprise codebases. CodeRabbit is engineered from the ground up with strict data isolation mechanisms, robust cryptographic standards, and enterprise compliance certifications to protect sensitive intellectual property.

#### 1. Ephemeral Memory Processing & Zero Data Retention
Unlike consumer AI tools that retain prompt histories, CodeRabbit enforces a strict Zero Data Retention (ZDR) policy across all review pipelines:

- **In-Memory Delta Evaluation**: Incoming code diffs, code-graph context, and pull request metadata are processed exclusively in volatile container memory during the review run.
- **Immediate Data Destruction**: As soon as CodeRabbit posts its review comments back to your pull request, the ephemeral container memory is scrubbed. Source code is not retained after the review completes, except when the optional review-caching feature is enabled; cached data is encrypted, used only to accelerate future reviews, never used for training, and expires automatically.
- **Encryption in Transit and at Rest**: All data transmitted between your version control provider and CodeRabbit is encrypted in transit using TLS and at rest.

#### 2. Strict Non-Training Guarantee on Proprietary IP
CodeRabbit states that your proprietary code is never used to train public or foundation LLM models.

**Third-Party LLM Provider Agreements**: CodeRabbit holds enterprise-level Zero Data Retention agreements with underlying model providers (an OpenAI Zero Data Retention amendment is published in the CodeRabbit Trust Center).

#### 3. Self-Hosted Deployment & Private-Network Connectivity
For enterprise organizations operating under strict air-gapped environments or healthcare/financial data residency mandates, CodeRabbit offers a self-hosted deployment option (Enterprise plan, 500+ seats).

- **Bring Your Own Model**: Self-hosted customers connect CodeRabbit to their own large language model provider or account, so review prompts are sent to infrastructure they control.
- **Network Isolation**: Source code, pull request data, and review traffic stay within a network boundary you control; code and prompt data leave it only to reach your configured LLM provider. A Reverse Tunnel option keeps all connections outbound for Git platforms without inbound access.

#### 4. Enterprise Compliance & Access Governance
CodeRabbit maintains continuous compliance audits to satisfy enterprise security review boards:

- **SOC 2 Type II Certification**: Independently audited for Security, Availability, and Confidentiality trust service criteria. CodeRabbit is also ISO 27001:2022 certified and GDPR compliant.
- **SAML 2.0 Single Sign-On (SSO)**: Enterprise plan customers can enforce centralized identity access control through their SAML identity provider.
- **Granular RBAC & Audit Logs**: Enterprise plan customers can configure role-based access control and inspect comprehensive audit logs tracking all review triggers, rule updates, and team member permissions.
- **Public API & Review Observability**: Enterprise organizations get API access for review metrics, Learnings, MCP usage and organization inventory, plus workspace-scoped API tokens. All Essentials-and-above organizations get a Review Usage dashboard that attributes every review event and rate-limit outcome to the pull request that caused it, and admins can set what happens when included review limits are reached: continue automatically, require on-demand consent, or stop.

### Configuration via .coderabbit.yaml & Custom Team Policies

Engineering managers can enforce team-specific review guidelines by committing a `.coderabbit.yaml` file to the root of the repository:

- **Review Profiles**: Choose between quiet, chill, assertive feedback profiles depending on project maturity.
- **Path Filtering**: Exclude auto-generated code files, vendor libraries, and build artifacts from review triggers.
- **Custom Guidelines**: Define custom linting rules and team standards (e.g., Require JSDoc documentation on all exported public API endpoints).
- **Cross-Repository Code Guidelines**: Keep engineering standards in one central repository and apply them across every repository CodeRabbit reviews, with `applyTo` patterns that scope each guideline to matching source files. Update the central file once and every subsequent review picks it up.
- **TypeScript Configuration**: For teams that need conditional logic, `.coderabbit.config.ts` defines settings programmatically with editor type-checking, reusable fragments and PR-aware conditions, for example, applying a stricter profile when a pull request is labelled hotfix. Existing YAML keeps precedence if both are present.
- **Configuration Inheritance**: Repository YAML, central organization YAML and UI settings can be merged rather than overridden, and commenting `@coderabbitai configuration` prints the effective configuration annotated with where each setting came from.
